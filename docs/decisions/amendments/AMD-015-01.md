# AMD-015-01 — Hai bảng con cho phạm vi của lần tính giá (FEAT-015)

Mã theo quy tắc tránh conflict (tiền tố FEAT).

- **Vấn đề**: `docs/data-model.md` 3.x, NC Costing Run: `scope_departments` và `scope_services` có kiểu **Table MultiSelect**. Frappe v15 chỉ lưu Table MultiSelect qua một DocType bảng con (`istable` = 1) có đúng một trường Link. `data-model.md` không đặt tên hai bảng con này, nên chúng chưa có trong danh mục DocType.
- **Phương án** (đơn giản nhất, theo đúng cách Frappe làm):
  - **NC Costing Run Department** (`istable` = 1, module NC Costing): một trường `department` (Link NC Department, BB, `in_list_view`).
  - **NC Costing Run Service** (`istable` = 1, module NC Costing): một trường `technical_service` (Link NC Technical Service, BB, `in_list_view`).
  - `scope_departments` → Table MultiSelect `NC Costing Run Department`; `scope_services` → Table MultiSelect `NC Costing Run Service`.
  - Quyền: bảng con theo quyền DocType cha (data-model mục 4, "Bảng con theo quyền của DocType cha"). Không có scope rule riêng, không có `delete_guard`.
  - `docs/data-model.md`, bảng NC Costing Run, cột Ghi chú của hai dòng `scope_departments`, `scope_services`: thêm "Bảng con `NC Costing Run Department` / `NC Costing Run Service`, một trường Link **[AMD-015-01]**". Mục danh sách bảng con (nếu có): thêm hai tên.
- **Tệp sửa**: `docs/data-model.md` (Dev áp ở T01 của FEAT-015), `normcore/nc_costing/doctype/nc_costing_run_department/`, `normcore/nc_costing/doctype/nc_costing_run_service/`, `normcore/nc_costing/doctype/nc_costing_run/nc_costing_run.json`.
- **Ảnh hưởng FEAT khác**: không đổi hành vi FEAT nào đã DONE. Test đếm DocType (nếu có, ví dụ `tests/test_permissions.py`) phải cập nhật số theo CLAUDE.md mục 3 luật 1, ngoại lệ "FEAT mới thêm DocType", có Quyết định Lead và ASM dẫn chứng (ASM-015-18). FEAT-018 (nhân bản, ảnh chụp) sao chép cả hai bảng con.
